## 1. 競合サロンSaaS LP分析

### KaruteKun（カルテくん）— karutekun.com
- **ヘッドライン**: 「美容サロン向けの電子カルテ・予約・売上管理をスマホ1つで簡単に!」
- **構成**: 業種別LPを用意（ヘア / エステ / アイラッシュ / ネイル）
- **デザイン**: ダークブルー + ピンク + スカイブルーのグラデーション系CTA
- **料金**: シングルプラン月額5,500円〜 / スタンダード月額11,000円〜。30日無料トライアル
- **CTA方式**: モーダル形式で複数回出現
- **特筆**: 業種別LP（/lp_101/beauty等）でターゲティングが精緻

### LiME（ライム）— limehair.jp
- **ヘッドライン**: 「美容師のカルテ管理をスマホで便利に!」
- **デザイン**: ティール(#15bfab) + ピンク(#e6417a)。カスタムフォント「mplus-2c」
- **アニメーション**: CTAボタンのフローティングアニメーション
- **料金**: 無料プラン（カルテ1人5枚、予約月5件）。有料は売上連動型
- **特筆**: 「美容師が企画設計した」を全面訴求。売上連動型で小規模サロンの障壁低

### Bionly → Aiony（アイオニー）— aiony.jp
- **ヘッドライン**: 「美容室の電子カルテと予約管理を低コストで全部搭載」
- **デザイン**: ネイビー + レッドアクセント。WordPress構築
- **料金**: iPad POSレジ型。月額5,000円〜9,800円
- **特筆**: iPadベースのPOSレジが差別化。コラム記事でSEO流入を狙う

### リザービア — rsvia.co.jp
- **ヘッドライン**: 「使いやすさで選ばれる予約システム リザービア」「リピート予約を増やし、集客コストを減らす」
- **構成**: ヒーロー（カルーセル）→ 信頼指標（7,000店舗）→ 業種カテゴリ → メリット → 機能 → 導入事例 → セミナー → ブログ
- **デザイン**: 白背景 + ピンクアクセントマーカー。プロサロン写真多用
- **料金**: 初期約10万 + 月額15,000〜21,000円。LP上では料金非表示で問い合わせ誘導
- **CTA**: 資料請求型（「今すぐ資料請求する」）
- **特筆**: 導入事例が業種別に充実。7,000店舗の信頼感

### STORES予約 — stores.fun/reserve
- **ヘッドライン**: 「予約の受付・管理を自動化し、手間を削減」「24時間365日、自動で予約を受け付けられる」
- **構成**: ヒーロー → 社会的証明（250,000社）→ メリット → 選ばれる理由 → 料金5プラン → 導入フロー → 業種別 → 事例 → FAQ
- **デザイン**: ブルー + ニュートラル。GSAP スクロール連動。**固定CTAナビ（スクロール追従）**
- **料金**: 5段階。Free(0円/月50予約) → Small(9,790〜12,980円) → Team(19,690〜22,880円) → Business(28,600〜31,790円) → Enterprise(66,000〜77,000円)
- **CTA**: ダブルCTA戦略（「無料ではじめる」+「資料ダウンロード」）
- **特筆**: 固定CTAバーがスクロール追従。最も体系的な料金表示

### Square予約 — squareup.com/jp/ja/appointments
- **ヘッドライン**: 「無料の予約システム | オンライン予約管理システム」
- **構成**: ヒーロー → フリップ/リビールのインタラクティブ機能タイル → 料金（タブ切替） → FAQ → 業種別 → 証言
- **デザイン**: ブルー(#006AFF) + ダークグリーン。料金スライダーUI
- **特筆**: グローバルブランドの安心感。フリップカード等のリッチインタラクション

## 2. 競合LPの共通パターン

### セクション構成の王道
1. ファーストビュー（価値命題 + CTA）
2. 信頼指標（導入数・ロゴウォール）
3. 課題提起（ターゲットの痛みに共感）
4. 機能/ベネフィット（解決策の提示 3〜4つ）
5. 料金（透明な価格表示）
6. 導入事例/声（第三者証拠）
7. 導入フロー（簡単さのアピール）
8. FAQ（不安の解消）
9. 最終CTA（クロージング）

### 全社共通の要素
- CTAは最低2箇所（ファーストビュー + ページ末尾）
- モバイル対応は全社必須対応済み
- 料金は（リザービア以外）LP上で明示
- FAQ セクションは全社に存在

### salon-karteが差別化できるポイント
- **価格**: 2,980円は競合最安帯（KaruteKun 5,500円の約半額）
- **全機能込み**: LINE連携・在庫・確定申告が追加費用なし
- **確定申告サポート**: 競合ゼロの唯一無二の機能
- **初期費用0円**: リザービア（10万円）やサロンアンサー（13万円）と対照的

## 3. コピーライティング原則

### 個人サロンオーナーに響く表現
1. **具体的な時間削減を数値で示す**: 「毎日30分のカルテ作業をゼロに」
2. **スマホ1つで完結を強調**: PCを持たないオーナーが多い
3. **専門用語を避ける**: 「SaaS」「クラウド」は使わない → 「スマホアプリ」「ネットで管理」
4. **業務シーンに寄り添う**: 「施術中でもサッと確認」「お客様が帰った後に3分で記録」
5. **ホットペッパー依存への共感**: 月額掲載料の高さ・リピーターが育たない課題

### 不安解消メッセージ（必須要素）
| 不安 | 解消メッセージ |
|------|--------------|
| 初期費用が怖い | 「初期費用0円。今日から使えます」 |
| 使いこなせるか | 「スマホ操作ができれば大丈夫」 |
| データ移行が面倒 | 「CSVインポートで既存データもカンタン移行」 |
| 契約の縛り | 「いつでも解約OK。縛りなし」 |
| サポート不安 | 「LINEでいつでも質問OK」 |
| 今のやり方で困ってない | 「紙カルテの限界」を数字で見せる |

### CTA文言の最適解
- **メインCTA**: 「無料ではじめる」（/signup へリンク）
- **副次CTA**: 「LINEで質問する」（LINE友だち追加）
- **マイクロコピー**: 「初期費用0円 / クレジットカード不要 / いつでも解約OK」
- **配置**: ファーストビュー(1回目) → 料金後(2回目) → 最終セクション(3回目) + 固定バー

## 4. コンバージョン最適化（CRO）

### サロンオーナーの心理的障壁と対処法
| 障壁 | 対処法 |
|------|--------|
| 「ITは苦手」 | UIスクリーンショット多用、操作ステップを3つで説明 |
| 「今のやり方で回ってる」 | 紙カルテの非効率さを数値化（年間XX時間の損失） |
| 「お金をかけたくない」 | 月額2,980円=1日99円、コーヒー1杯以下 |
| 「ホットペッパーで十分」 | ホットペッパー月額5〜15万 vs salon-karte 2,980円 |
| 「データが消えたら怖い」 | クラウド自動バックアップを明示 |
| 「お客様に迷惑がかかる」 | 段階的移行が可能であることを説明 |

### 問い合わせチャネルの優先順位
1. **LINE友だち追加**（最適 — サロンオーナーは日常的にLINE利用）
2. **無料登録（Web）**（即座に体験開始）
3. **問い合わせフォーム**（ハードルが高い）
4. **電話**（施術中は対応不可 → 不向き）

### 固定CTAバー（STORES予約方式）
- スクロール追従のCTAバーがコンバージョンに最も効果的
- モバイルでは画面下部に固定
- デスクトップではヘッダーに固定

## 6. 日本語フォント選定

2025年4月にWindows 10/11にNoto Sans JPが標準搭載され、環境が大きく変化。

### 推奨
```css
font-family: "Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", sans-serif;
```

- Windows/Mac/iOS/Android全環境で統一的な表示が可能
- salon-karteの既存設定と同一
- Noto Sans JP の Regular(400) + Bold(700) で十分
- LP見出しのみ: M PLUS Rounded 1c（角丸で温かみ）を検討可

## 7. 2026年 SaaS LP デザイントレンド

### 成功事例から抽出（Linear, Notion, Stripe, Vercel, Framer, Arc, Raycast）

1. **プロダクトデモがヒーロー**: スクリーンショットではなくインタラクティブデモ
2. **ダークモードが標準**: 高コントラスト、読みやすさ、高級感
3. **グラスモーフィズム**: 半透明+ブラー+影でガラスのような効果
4. **ナラティブヘッドライン**: 機能列挙ではなくストーリーを伝える
5. **最小限の意味あるモーション**: フラッシュではなく理解促進のアニメーション
6. **社会的証明の戦略的配置**: ファーストビューにロゴバー + テスティモニアル

### salon-karteへの適用判断
- ダークモード → **不採用**（ターゲットのサロンオーナーにはライト・温かい色調が合う）
- グラスモーフィズム → **部分採用**（機能カード等にさりげなく）
- プロダクトデモ → **採用**（スマホモックアップ + スクリーンショット）
- ナラティブヘッドライン → **採用**（「カルテも予約もLINEも。月額2,980円で、ぜんぶ。」）
