## リリース判断の基本方針

**商用リリースのトリガーは「プロダクトの準備完了」ではなく「需要の確認」。**

- 見込み客が1社しかいない状態で月$45の固定費を発生させない
- Stripeゲートはテスターの検証を妨げるので、需要確認前には入れない
- テスターのフィードバックを全て回収し品質を上げてから、需要検証に進む

## Phase 2: 商用リリース準備

> 目的: 課金を開始する。
> 前提: Phase 1 完了（需要確認済み）
> 期間: 1-2週間

### インフラ移行

| # | タスク | 担当 |
|---|--------|------|
| 2-1 | Vercel Hobby → Pro 移行 | オーナー手動 |
| 2-2 | Supabase Free → Pro 移行 | オーナー手動 |
| 2-3 | Stripe 本番モード有効化（本人確認・銀行口座） | オーナー手動 |
| 2-4 | 環境変数を本番キーに更新 | オーナー + Claude |
| 2-5 | Webhook エンドポイントを本番 URL で再登録 | オーナー手動 |
| 2-6 | Resend 独自ドメイン認証（SPF/DKIM/DMARC） | オーナー + Claude |

### コスト影響
- Vercel Pro: $20/月（約3,000円）
- Supabase Pro: $25/月（約3,750円）
- 合計: 約6,750円/月
- 損益分岐: 3サロン契約で月8,940円 > 固定費6,750円

### 機能ゲート実装

| ゲート | 対象ページ | チェック内容 |
|--------|----------|------------|
| 顧客数上限 | `/customers/new` | Free: 10件まで |
| カルテ数上限 | `/records/new` | Free: 1顧客あたり5件まで |
| 予約数上限 | `/appointments/new` | Free: 月20件まで |
| 写真機能 | カルテ写真アップロード | Free: 利用不可 |
| LINE連携 | `/settings/line` | Free: 利用不可 |
| カウンセリング | `/settings/counseling-template` | Free: 利用不可 |
| 売上分析 | `/sales/analytics` | Free: 当月のみ |

実装方針:
- Server Component: `getAuthAndSalon()` で `plan_type` を取得 → props 経由で制限情報を渡す
- Client Component: `<FeatureGate>` ラッパーで制限超過時にアップグレード案内を表示
- API: POST/INSERT 時にも DB 側でカウントチェック
