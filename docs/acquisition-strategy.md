## 0. 最重要の問い: 「3サロン確約まで待つべきか？」

### 結論: 待つ戦略は正しい。ただし「待つ」と「何もしない」は違う。

| 判断 | 理由 |
|------|------|
| Supabase/Vercel課金は待つ ✅ | 月$45の固定費を1サロンの状態で発生させる合理性がない |
| Stripeテストモードも待つ ✅ | 決済導線はテスターの検証を妨げない現在の設計で正しい |
| **集客活動は今すぐ始める** ⚠️ | 「3サロン」は待っていても来ない。能動的に取りに行く必要がある |

### 数字で見る現実

```
現在: テスター1サロン（有料意思あり）
目標: 3サロン確約

必要なアクション:
- SEO記事 → 検索流入 → LP → サインアップ の導線構築
- SEO効果が出るまで3〜6ヶ月 → 今日始めないと遅い
- コスト: 0円（既存のブログ機能で記事を公開するだけ）
```

**結論: インフラ課金は待つ。集客活動は今すぐ始める。この2つは矛盾しない。**

### 2.3 記事品質基準（100点の記事とは）

#### 記事構成テンプレート

```
1. リード文（150字以内）
   - 読者の悩みを代弁 → 解決策の提示 → 記事を読むメリット
   - AI検索に拾われやすい「結論ファースト」

2. 目次（自動生成）

3. 課題提起セクション
   - 読者の「あるある」を3つ具体的に描写
   - 共感 → 「このままだとこうなる」危機感

4. 解決策セクション（メイン）
   - 具体的な手順・方法を図解付きで解説
   - 自社プロダクトへの自然な言及（押し売りではなく）
   - 実体験ベースの一次情報を必ず含める

5. 比較・選択肢セクション（ボトムファネル記事の場合）
   - 公平な比較表（自社だけ持ち上げない）
   - 各ツールの向き不向きを正直に書く

6. まとめ + CTA
   - 要点3つの箇条書き
   - 「無料ではじめる」への自然な誘導
   - マイクロコピー: 初期費用0円 / クレジットカード不要

7. 著者プロフィール（E-E-AT対策）
   - 「個人サロン向けアプリ開発者」としての経歴
   - なぜこのテーマに詳しいかの根拠
```

## 3. SEO以外の集客戦略

### 3.1 紹介プログラム強化（優先度A — 実装済み）

**現状**: 紹介コード + 双方1ヶ月無料が実装済み。

**強化案**:
- テスターに紹介を**直接お願いする**（最も効果的なのは人的な依頼）
- 紹介しやすい素材を用意（1枚のスクリーンショット + 30秒の説明文）
- テスターの成功事例を紹介文として共有許可をもらう

**期待効果**: CAC $150相当（業界最低水準）

### 3.2 無料ツール提供（優先度A — 新規）

> 「記事を書くのではなく、無料ツールを作れ」(2026 SaaS SEO Playbook)

**アイデア**:
- **売上シミュレーター**: 「月間客数×客単価」で年収を即計算。salon-karteの確定申告機能への導線
- **予約空き枠カレンダー**: 営業時間を入力すると空き枠が可視化。予約管理機能への導線
- **施術メニュー料金テンプレート**: 地域別の相場データ付き。メニュー管理機能への導線

**メリット**: 被リンク獲得 + SEO + リード獲得を同時達成

### 3.3 パートナーシップ（優先度B）

**候補**:
- **サロン開業支援の行政書士・税理士**: 開業時にsalon-karteを紹介してもらう
- **美容ディーラー（材料卸）**: 顧客のサロンに推薦
- **サロン向けスクール・セミナー講師**: 受講者への紹介

**アプローチ**: 相互紹介 or 紹介手数料（1契約あたり1ヶ月分）

### 3.4 コミュニティ参加（優先度B）

**候補**:
- **サロンオーナー向けFacebookグループ**: 質問に回答 → 信頼構築 → 自然な紹介
- **個人サロン経営者の掲示板・フォーラム**: ノウハウ共有
- **note / Zenn**: 「個人でSaaSを作った話」の開発ストーリー記事 → 開発者コミュニティからの流入

**注意**: 宣伝目的の投稿はNG。まず価値を提供し、聞かれたら紹介するスタンス。

### 3.5 Product-Led Growth強化（優先度A）

#### 現在の課金モデル評価

**2026年のコンバージョン率ベンチマーク:**
- フリートライアル（カード不要）: **15〜25%** コンバージョン
- フリートライアル（カード必要）: **50〜60%** コンバージョン
- フリーミアム: **2〜5%** コンバージョン
- **リバーストライアル**: フルアクセス → 期限後にフリーミアムに降格（Slack方式）

**salon-karteへの推奨:**
1. **30日間フルアクセス無料トライアル**（カード不要）
2. 30日後に機能制限（顧客数上限 or 写真保存上限）
3. 有料プランへの移行を促す

**理由**:
- サロンオーナーはITリテラシーが低い → カード要求でドロップする
- サロン業務は「使ってみないと価値がわからない」→ 体験が必須
- 30日あれば数回の施術記録を作成でき、データの蓄積が解約のスイッチングコストになる

## 5. 総括

### やること（優先順）
1. **SEO記事を書く**（最も効率が高く、コスト0円）
2. **テスターに紹介を直接お願いする**（既に実装済みの仕組みを活用）
3. **無料ツールを1つ作る**（SEO+リード獲得の一石二鳥）
4. **開発ストーリーをnote/Zennに書く**（開発者コミュニティからの認知）

### やらないこと
- SNS毎日投稿（運用コストに見合わない）
- Google Ads（CPC高騰で予算が足りない）
- インフラ課金（3サロン確約まで待つ）

### 最も重要な1つ
**今日、SEO記事の第1本目を書き始めること。** SEOは効果が出るまで3〜6ヶ月かかる。
1日遅れるごとに、3サロン到達が1日遅れる。
