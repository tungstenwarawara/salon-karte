## 1. LP制作ツール・サービス

### Nano Banana Pro（ナノバナプロ）
Google が2025年11月リリースしたAI画像生成モデル（Gemini 3 Pro Image）。

| 項目 | 詳細 |
|------|------|
| 主な機能 | 日本語テキスト入りバナー/LP素材の生成、14枚の参照画像の同時読み込み、4K出力、部分編集 |
| 料金 | Google AIの各プラン経由で利用可能（無料枠あり） |
| LP活用 | ヒーローバナー、CTA付き画像、SNS広告素材の即時生成。日本語が崩れない点が最大の強み |
| 後継 | 2026年2月に Nano Banana 2（Gemini 3.1 Flash Image）リリース。生成速度4-6秒、API費用約50%削減 |

**salon-karte向け**: サロンの雰囲気を伝えるビジュアル素材やバナー画像の生成に有効

### Framer
| 項目 | 詳細 |
|------|------|
| 特徴 | ノーコードWebサイトビルダー。デザイン + ホスティング一体型 |
| 料金 | Mini: $5/月（2ページ）、Basic: $15/月、Pro: $30/月 |
| 強み | マイクロインタラクション/モーションデザインが圧倒的 |
| 弱み | 既存Next.jsコードベースとの統合は不可 |

**判定**: 別ドメインでLP単体を作る場合に有力。だが既存Next.jsに統合する方が運用が楽。

### v0.dev (Vercel)
| 項目 | 詳細 |
|------|------|
| 特徴 | プロンプトからReact + Tailwindコンポーネントを生成するAIツール |
| 料金 | Free: $0（$5クレジット付）、Premium: $20/月 |
| 強み | 生成UIの品質が全AIビルダー中最高。shadcn/uiパターン準拠。Next.jsとの親和性最高 |

**判定**: 各セクションのベースコンポーネント生成に活用可能

### Lovable
| 項目 | 詳細 |
|------|------|
| 特徴 | フルスタックAIアプリビルダー。自然言語からフロント+バックエンドを一括生成 |
| 料金 | Free: 5日次クレジット、Pro: $25/月 |
| 強み | Supabase統合あり |
| 弱み | 既存コードベースへの組み込みが困難 |

**判定**: 新規プロジェクト向き。salon-karteでは不使用。

### Canva / Adobe Express
| 項目 | Canva | Adobe Express |
|------|-------|--------------|
| テンプレート数 | 61万点以上 | 35万点以上 |
| Pro料金 | 約1,500円/月 | 約1,500円/月 |
| LP活用 | バナー、OGP画像、SNS素材の制作 | 動画素材、高品質素材 |

**判定**: 補助素材制作に使う。LP本体の構築には使わない。

## 2. アニメーションライブラリ

| ライブラリ | サイズ | 学習コスト | LP向き度 | 料金 | 推奨用途 |
|-----------|-------|-----------|---------|------|---------|
| **Motion (旧Framer Motion)** | ~33KB | 低 | ★★★★★ | 無料 | スクロールアニメーション、hover、ページ遷移 |
| **GSAP + ScrollTrigger** | ~23KB+ | 中 | ★★★★★ | **完全無料化**（2025年〜） | 高度なスクロール連動、パララックス |
| **Lottie** | ~82KB | 低 | ★★★☆☆ | 無料 | After Effectsアニメーション埋め込み |
| **Three.js / R3F** | ~150KB+ | 高 | ★★☆☆☆ | 無料 | 3D背景（salon-karteにはオーバースペック） |
| **Rive** | ~60KB | 中 | ★★★★☆ | Free〜$50/月 | インタラクティブアバター |
| **AOS / TAOS** | 8KB/0.6KB | 極低 | ★★★☆☆ | 無料 | シンプルなスクロールフェードイン |
| **Tailwind CSS animations** | 0KB | 極低 | ★★★☆☆ | 無料 | 基本的なpulse/spin/bounce |

### 推奨組み合わせ
- **Motion**: メインのアニメーションエンジン（スクロール連動、フェードイン、カウントアップ）
- **Tailwind CSS**: 微細なアニメーション（hover、ローディング）
- GSAP は Motion でカバーできない高度な場合のみ

## 3. 動画制作ツール

| ツール | 用途 | 料金 | LP向き度 |
|-------|------|------|---------|
| **Screen Studio** | macOS高品質画面録画（自動ズーム・カーソルハイライト） | $229買い切り | ★★★★★ |
| **CapCut** | 動画編集（AI字幕、テンプレート） | Free〜$9.99/月 | ★★★★☆ |
| **HeyGen** | AIアバター動画（175言語・日本語対応） | Free〜$29/月 | ★★★★☆ |
| **Loom** | スクリーン録画+共有 | Free（5分）、$12.50/月 | ★★★☆☆ |
| **Synthesia** | AIプレゼンター（法人向け） | $29/月〜 | ★★★☆☆ |
| **Runway ML** | AI動画生成（Gen-4） | 月額クレジット制 | ★★★☆☆ |
| **Sora (OpenAI)** | AI動画生成 | $200/月（Pro） | ★★☆☆☆ |

### 推奨ワークフロー
1. **Screen Studio** でアプリ操作画面を録画（自動ズームで操作の簡単さを伝達）
2. **CapCut** でテロップ・BGM・AI字幕を追加して30秒のデモ動画に仕上げ
3. オプション: **HeyGen** で「サロンオーナーが語る」AIアバター紹介動画を制作

## 4. 画像・イラスト素材

### AI画像生成
| ツール | 料金 | 得意領域 | 商用利用 |
|-------|------|---------|---------|
| **Midjourney** | $10-$120/月 | 芸術的・高品質画像 | 有料プランで可 |
| **DALL-E 3** | ChatGPT Plus $20/月 | 日常的なAI画像生成 | 可 |
| **Stable Diffusion** | 無料（ローカル）| フルカスタマイズ | 可 |
| **Nano Banana Pro** | Google AI枠内 | 日本語テキスト入り素材 | 要確認 |

### 無料イラスト・写真
| サービス | 特徴 | 料金 |
|---------|------|------|
| **unDraw** | クリーン/モダンなSVGイラスト。カラー変更可 | 完全無料 |
| **Storyset** | アニメーション付きイラスト。Lottie対応 | 無料（Freepik提供） |
| **Unsplash / Pexels** | 高品質写真。商用利用可 | 無料 |

### salon-karte向け推奨
- **ヒーロー画像**: Midjourney or Nano Banana Pro で「サロンオーナーがタブレットで管理」のイメージ生成
- **機能説明イラスト**: unDrawのSVGをアクセントカラー（#C4956A）にカスタマイズ
- **背景写真**: Unsplash/Pexelsから美容サロンの雰囲気写真
