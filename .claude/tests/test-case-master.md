# 業務フロー型テストケースマスター

> 最終更新: 2026-04-21
> 対象: salon-karte 全機能（現在: 65ページ・18 APIルート・67マイグレーション）
> テスト方式: Claude Preview MCP による自動UI検証 + 手動確認項目
>
> 規模は変動するため、セッション開始時の statusLine（`📄XX 🗂XX`）で実測値を確認すること。

## テストサロン（必須）

- **全テストはテストサロンアカウントで実施すること**
- ログイン先: テストサロン花 (`salon_id: 00000000-0000-0000-0000-000000000001`)
- 認証情報: `.claude/rules/test-salon.md` を参照
- テストデータリセット: `npx tsx scripts/seed-test-data.ts --reset`
- **本番アカウントでのテスト実施は禁止**（実オーナーのデータは個人情報）

## 2026-02-27以降の主な追加機能（未網羅のケースあり）

以下は 2026-02-27 以降に追加されたもので、このテストケース集に未反映のため、
該当箇所を変更した際はアドホックにテストを追加すること。

- スタッフ管理・シフト（`/settings/staff`, `/settings/staff-schedule`）
- カウンセリングテンプレート（`/settings/counseling-template`）
- LINE連携（`/settings/line` + webhook + cron リマインド）
- オンボーディングチェックリスト（`OnboardingChecklist`）
- LP 全セクション（hero/problem/features/showcase/pricing/comparison/faq 他）
- ブログ（`/blog/*`、6記事）
- サインアップファネル計測（`signup_form_submit` / `email_confirmed`）
- Stripe サブスクリプション決済

## テスト実施ルール

1. **コミット＆プッシュ後（必須）**: 変更ファイルに基づきテスト選定ガイドで対象フローを決定し、`[AUTO]` ケースを Claude Preview MCP で実行
2. **リリース前**: 全フローの「MUST」ケースを実行
3. **判定基準**: 各ケースに ✅PASS / ❌FAIL / ⚠️WARN を記録
4. **❌FAIL 発生時**: その場で修正→再テスト→再コミット＆プッシュ
5. **自動化可能**: `[AUTO]` マーク付きは Claude Preview MCP で自動実行可能
6. **手動マーク**: ファイルアップロード・ブラウザリロード等はユーザーに確認依頼

## レベル別の使い分け（CLAUDE.md の検証レベルに対応）

| レベル | 対象 | このマスターの使い方 |
|--------|------|-------------------|
| 1 | CSS/ドキュメントのみ | 不要。ビルド検証のみ |
| 2 | 特定ページのロジック変更 | 該当フローの [AUTO] ケースのみ実行 |
| 3 | DB・認証・複数領域変更 | 該当フローの MUST ケース全実行 |
