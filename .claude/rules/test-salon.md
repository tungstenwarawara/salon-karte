# テストサロン ルール（厳守）

## 基本原則
- **業務テスト（Claude Preview MCP）には必ずテストサロンアカウントを使用する**
- **本番サロンアカウント（実オーナーのアカウント）でのテストは絶対禁止**
- テスト中に本番データ（実顧客名、カウンセリング回答等）を閲覧・操作しない
- 本番アカウントのパスワードリセットは禁止

## テストサロン情報
- サロン名: テストサロン花
- サロンID: `00000000-0000-0000-0000-000000000001`
- メールアドレス: `test-salon@salon-karte.dev`
- パスワード: `TestSalon2026!`

## テストサロンへのログイン手順
1. `preview_start(name: "dev")` で dev server 起動
2. `/login` ページに遷移
3. 上記テスト認証情報でログイン
4. ダッシュボードに「テストサロン花」と表示されることを確認

## テストデータ概要
| テーブル | 件数 | 備考 |
|---------|------|------|
| 顧客 | 25 | ページネーション・離脱・卒業済みテスト用 |
| メニュー | 6 | 非アクティブ1件含む |
| カルテ | 30 | 3ヶ月分散（期間フィルターテスト用） |
| 予約 | 15 | 当日3件・完了・キャンセル |
| 商品 | 5 | 発注点以下アラート1件 |
| 回数券 | 4 | 利用中・消化済み・期限切れ |
| 物販 | 10 | 商品リンク+自由入力 |
| カウンセリング | 3 | pending + submitted（カスタムテンプレ回答） |

## テストデータのリセット
テストデータが壊れた場合:
```bash
npx tsx scripts/seed-test-data.ts --reset
```
※ `--reset` なしで実行すると、テストサロンが既に存在する場合は何もしない

## 禁止事項
- 本番アカウント（luica_sazawa, tungstenwarawara 等）でのログイン
- 本番アカウントのパスワードリセット
- テストサロン以外の salon_id を使った手動データ操作
- テスト認証情報の git コミット（.env.local は gitignore 済み）
